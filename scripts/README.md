# Scripts & Utilities

This directory contains utility scripts for testing, deployment, and demo generation.

## 🧪 Test Scripts

### API Testing
- **test_yutori.py** - Test Yutori API connection and research functionality
- **test_freepik_kling.py** - Test Freepik Kling video generation API
- **test_instant_playback.py** - Test video playback functionality

### Demo Generation
- **generate_demo_video.py** - Generate demo videos for presentations

## 🚀 Deployment Scripts

- **push_to_github.sh** - Automated git push with pre-flight checks

## 📖 Usage

### Test Yutori API
```bash
cd ..
python scripts/test_yutori.py
```

### Test Freepik Kling
```bash
cd ..
python scripts/test_freepik_kling.py
```

### Generate Demo Video
```bash
cd ..
python scripts/generate_demo_video.py
```

### Push to GitHub
```bash
cd ..
./scripts/push_to_github.sh
```
